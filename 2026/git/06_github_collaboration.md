# 発展編：GitHub を使いこなす

コードを共有するだけでなく、GitHub の機能をフル活用して開発をスムーズに進める方法を紹介します。

---

## 💬 コードレビューを体験しよう

プルリクエスト（PR）は、単にコードを合体させるためだけのものではありません。

- **コメント機能**: PR の特定の行に対して「ここ、もっとこうした方が良さそう！」とアドバイスを送れます。
- **Approve（承認）**: チームメンバーがコードをチェックし、「OK！」と太鼓判を押すことでマージを許可します。

> [!TIP]
> レビューは「間違い探し」ではなく、**「より良いコードを一緒に作る相談」**です。ポジティブな言葉遣いを心がけましょう！

---

## 🎫 Issue（イシュー）でタスク管理

「やりたいこと」や「見つけたバグ」をメモしておく掲示板のような機能です。

- **TODO リストとして**: 「B問題を解く」「リファクタリングする」などを登録します。
- **議論の場として**: 解決方法をコメント欄で相談できます。
- **紐付け**: コミットメッセージに `fixed #1`（1番のIssueを解決）と書くと、自動的にその Issue が閉じられます。

---

## 🖥️ GUI ツールで視覚的に操作する

黒い画面（ターミナル）が苦手な人や、変更箇所を分かりやすく確認したい人には GUI ツールがおすすめです。

### 1. VS Code 内蔵の Git 機能（一番オススメ！）
VS Code を使っているなら、左側の「ソース管理」アイコンから操作できます。
- **差分が見やすい**: 変更前と変更後のコードが左右に並んで表示されます。
- **ステージングもクリック一つ**: `+` ボタンを押すだけで `git add` できます。

### 2. GitHub Desktop
GitHub 公式のアプリです。非常にシンプルで、初心者でも迷わず `clone`, `commit`, `push` ができます。

---

## 💡 アドバイス

> [!NOTE]

> コマンドラインにこだわる必要はありません。自分に合った道具（VS Code, GitHub Desktop など）を使って、楽しく効率的に開発できるのが一番です。
