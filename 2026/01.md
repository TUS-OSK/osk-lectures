## はじめに
この講義では、プログラミングをほとんど触ったことがない人でも、C++ を使って AtCoder の問題に挑戦できるようになることを目標としています。

この資料は、C++ を実行するための環境構築が終わっていて、AtCoder のアカウントを持っていることを前提に進めます。

最終的には、毎週土曜日に開催されている AtCoder Beginner Contest (ABC) で、A問題を安定して解き、B問題や簡単なC問題にも挑戦できるような実力を目指します。

競プロ以外の班に所属する予定の方でも、ABC のB問題程度を解くことができる実力はどの班でも必要になるので、ぜひ取り組んでください。

> [!WARNING]
> プログラミングは、資料を読んでいるだけでは身につきません。 この資料に出てくるコードは、必ず自分で入力し、実行する前に「何が出力されるか」を予想してから実行してください。

## 今回のゴール
この回では、C++ のプログラムの「基本形」を覚え、変数、入力、出力を使って簡単なA問題を解けるようになることを目標にします。

## 1.1 ターミナルの準備と実行
C++ のプログラムは、書いただけでは実行されません。ターミナルでコンパイルしてから実行します。

### ディレクトリを作る
まず、競技プログラミング用のディレクトリを作ります。ここでは `kyopro` という名前にします。

**ターミナル**

```bash
mkdir kyopro
```

`mkdir kyopro` は、今いる場所に `kyopro` というディレクトリを作るコマンドです。

次に、作った `kyopro` ディレクトリへ移動します。

**ターミナル**

```bash
cd kyopro
```

`cd kyopro` は、`kyopro` ディレクトリに移動するコマンドです。

今いるディレクトリは `pwd` で確認できます。

**ターミナル**

```bash
pwd
```

### main.cpp を作る
`kyopro` ディレクトリの中に、C++ のプログラムを書くための `main.cpp` を作ります。

**ターミナル**

```bash
touch main.cpp
```

`touch main.cpp` は、今いるディレクトリに `main.cpp` というファイルを作るコマンドです。

このあと、エディタで `main.cpp` を開いて、プログラムを書きます。

### コンパイルと実行
`main.cpp` があるディレクトリにいる状態で、次のように実行できます。

**ターミナル**

```bash
g++ main.cpp
./a.out
```

`g++ main.cpp` は、今いるディレクトリにある `main.cpp` をコンパイルするコマンドです。このように実行ファイルの名前を指定しない場合、同じディレクトリに `a.out` という名前の実行ファイルが作られます。

`./a.out` は、今いるディレクトリにある `a.out` を実行するコマンドです。

別のディレクトリにいると、`main.cpp` や `a.out` が見つからず、コンパイルや実行ができません。

プログラムを修正した後は、もう一度コンパイルしてから実行してください。

## 1.2 C++ の基本形と出力
C++ のプログラムは、まず次の形を覚えてください。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << "Hello, OSK!" << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
Hello, OSK!
```

最初は、それぞれの行を完全に理解していなくても大丈夫です。まずは「C++ のプログラムはだいたいこの形から始まる」と覚えましょう。

### 各行の意味
`#include <bits/stdc++.h>` は、C++ でよく使う道具をまとめて読み込むための行です。

AtCoder ではこの書き方がよく使われます。文字を出力する `cout` や、後で使う `vector`、`string` なども、この行によって使えるようになります。

`using namespace std;` は、`cout` や `endl` などを短く書けるようにするための行です。

**ソースコード**

```cpp
int main() {
    cout << "Hello, OSK!" << endl;
}
```

実行結果は次のようになります。

**実行結果**

```text
Hello, OSK!
```

ここがプログラムの本体です。

C++ のプログラムは、基本的に `main` の中に書いた処理が上から順番に実行されます。

`cout` は画面に出力するための命令です。`"Hello, OSK!"` のように `"` で囲んだ部分は文字列として扱われます。

`endl` は改行を表します。

## 1.3 四則演算
C++ では、数式を書くことで計算できます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << 3 + 5 << endl;
    cout << 10 - 4 << endl;
    cout << 6 * 7 << endl;
    cout << 20 / 3 << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
8
6
42
6
```

C++ で使う主な計算記号は次の通りです。

| 記号 | 意味 |
| --- | --- |
| `+` | 足し算 |
| `-` | 引き算 |
| `*` | 掛け算 |
| `/` | 割り算 |

掛け算には `×` ではなく `*` を使います。割り算には `÷` ではなく `/` を使います。

> [!WARNING]
> 整数どうしを `/` で割ると、答えも整数になります。小数部分は切り捨てられます。
>
> そのため、$20 \div 3$ の結果は $6.666...$ ではなく $6$ になります。
>
> 小数として割り算したいときは、どちらか一方を小数にします。
>
> **ソースコード**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     cout << 20.0 / 3 << endl;
>     cout << 20 / 3.0 << endl;
> }
> ```
>
> 実行結果は次のようになります。
>
> **実行結果**
>
> ```text
> 6.66667
> 6.66667
> ```
>
> このように書くと、小数として計算されます。

### 剰余演算
割り算の余りを求めるには `%` を使います。これを剰余演算といいます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << 20 % 3 << endl;
    cout << 10 % 2 << endl;
    cout << 10 % 4 << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
2
0
2
```

$20$ を $3$ で割ると、商は $6$、余りは $2$ です。そのため、`20 % 3` の結果は $2$ になります。

剰余演算は、数が偶数か奇数かを調べるときや、周期的な処理をするときによく使います。

### 零除算
> [!WARNING]
> $0$ で割ることを零除算といいます。
>
> C++ では、`/` や `%` の右側に `0` を書いてはいけません。
>
> **書いてはいけない例**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     cout << 10 / 0 << endl;
>     cout << 10 % 0 << endl;
> }
> ```
>
> このプログラムには、正常な実行結果はありません。実行するとエラーになるか、プログラムが途中で止まります。この例は実行せず、$0$ で割ってはいけないことだけ確認してください。
>
> 数学でも $10 \div 0$ は定義されていません。C++ でも同じように、$0$ で割る計算はできません。

### 演算子の優先順位
C++ の計算にも、数学と同じように優先順位があります。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << 2 + 3 * 4 << endl;
}
```

実行結果は次のようになります。

**実行結果**

```text
14
```

このプログラムでは、先に $3 \times 4$ が計算されます。そのため、結果は $20$ ではなく $14$ になります。

`*`、`/`、`%` は、`+`、`-` より先に計算されます。

計算する順番を変えたいときや、順番を分かりやすくしたいときは、括弧 `()` を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << (2 + 3) * 4 << endl;
}
```

実行結果は次のようになります。

**実行結果**

```text
20
```

この場合は、先に $2 + 3$ が計算されるので、結果は $20$ になります。

複雑な式を書くときは、優先順位に頼りすぎず、括弧を使って分かりやすく書くことが大切です。

## 1.4 変数
変数は、値に名前をつけて保存しておくためのものです。

### int 型
整数を保存したいときは `int` 型を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x;
    x = 10;
    cout << x << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
10
```

`int x;` は、`x` という名前の整数用の変数を用意するという意味です。これを変数の宣言といいます。

`x = 10;` は、変数 `x` に `10` を入れるという意味です。これを代入といいます。

数学では `=` は「等しい」という意味ですが、C++ では「右側の値を左側の変数に入れる」という意味で使います。

`cout << x << endl;` と書くと、変数 `x` に入っている値が出力されます。

宣言と代入は、次のように同時に書くこともできます。

**ソースコード**

```cpp
int x = 10;
```

代入する値には、計算式を書くこともできます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3;
    int b = 5;
    int sum = a + b;
    int product = a * b;
    cout << sum << endl;
    cout << product << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
8
15
```

`int sum = a + b;` では、先に $a + b$ が計算され、その結果が `sum` に代入されます。

> [!NOTE]
> 変数の名前には、アルファベット、数字、`_` を使うことができます。ただし、数字から始めることはできません。
>
> **使える例**
>
> ```cpp
> int score = 100;
> int abc123 = 45;
> int user_count = 3;
> ```
>
> 次のような名前は使えません。
>
> **使えない例**
>
> ```text
> int 1st = 10;
> int user-count = 3;
> ```
>
> 変数名は、後から読んだときに意味が分かる名前にしましょう。例えば、点数を表す変数なら `x` よりも `score` の方が分かりやすいです。

同じ型の変数は、次のようにまとめて宣言することもできます。

**ソースコード**

```cpp
int a, b, c;
```

値を入れながらまとめて宣言することもできます。

**ソースコード**

```cpp
int a = 3, b = 5, c = 8;
```

ただし、最初のうちは1行に1つずつ書いた方が読みやすいことも多いです。慣れるまでは、分かりやすさを優先しましょう。

### double 型
`double` は小数を扱うときに使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    double pi = 3.14;
    cout << pi << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
3.14
```

### long long 型
`long long` は、`int` に入りきらないような大きな整数を扱うときに使います。競技プログラミングでは、答えがとても大きくなる問題でよく使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    long long population = 8000000000;
    cout << population << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
8000000000
```

### char 型
`char` は1文字を扱うときに使います。`char` の値は `'A'` のようにシングルクォート `'` で囲みます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'A';
    cout << c << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
A
```

### string 型
`string` は文字列を扱うときに使います。`string` の値は `"AtCoder"` のようにダブルクォート `"` で囲みます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "AtCoder";
    cout << s << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
AtCoder
```

`char` は1文字、`string` は文字列です。`'A'` と `"A"` は似ていますが、C++ では別の型として扱われます。

> [!NOTE]
> ここまでに紹介した、よく使う型をまとめると次のようになります。
>
> | 型 | 保存できる値の例 | 説明 |
> | --- | --- | --- |
> | `int` | `10`, `-3` | 整数（約 $-2 \times 10^9$ から $2 \times 10^9$） |
> | `long long` | `10000000000` | 大きな整数（約 $-9 \times 10^{18}$ から $9 \times 10^{18}$） |
> | `double` | `3.14`, `-0.5` | 小数 |
> | `char` | `'A'`, `'x'` | 1文字 |
> | `string` | `"hello"`, `"AtCoder"` | 文字列 |

## 1.5 出力
ここまでのコードでもすでに使っていますが、計算結果や変数の中身を画面に表示するには `cout` を使います。

### 基本の出力
`cout << 出力したいもの << endl;` と書くと、値を出力して改行できます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 10;
    cout << x << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
10
```

`endl` は改行を表します。出力の最後に `endl` をつけると、次の出力は次の行に表示されます。

### 複数の値の出力
`<<` をつなげると、複数の値を1つの `cout` で出力できます。

`cout` は、左から順番に値を出力します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3;
    int b = 5;
    cout << a << " " << b << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
3 5
```

このプログラムでは、`a`、`" "`、`b`、`endl` の順に出力されます。そのため、`3` と `5` の間に空白が入ります。

AtCoder では、答えを空白区切りで出力する問題もよくあります。

### 改行区切りの出力
値を別々の行に出力したいときは、`endl` を複数回使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3;
    int b = 5;
    cout << a << endl;
    cout << b << endl;
}
```

このプログラムを実行すると、次のように表示されます。

**実行結果**

```text
3
5
```

出力形式は問題ごとに指定されています。空白区切りなのか、改行区切りなのかをよく確認してから出力しましょう。

## 1.6 入力
AtCoder の問題では、プログラムに値が与えられます。この値を受け取るには `cin` を使います。

### 基本の入力
整数を1つ受け取るときは、次のように書きます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x;
    cin >> x;
    cout << x << endl;
}
```

例えば、実行してから次のように入力します。

**入力**

```text
10
```

すると、次のように表示されます。

**実行結果**

```text
10
```

`int x;` で整数を入れる変数 `x` を用意しています。

`cin >> x;` は、入力された値を変数 `x` に入れるという意味です。

`cout` では `<<` を使いましたが、`cin` では `>>` を使います。向きが違うので注意しましょう。

### 複数の変数への入力
複数の変数に値を入れたいときは、`>>` をつなげて書くことができます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a;
    int b;
    cin >> a >> b;
    cout << a + b << endl;
}
```

入力が次のとき、

**入力**

```text
3 5
```

出力は次のようになります。

**実行結果**

```text
8
```

`cin` は左から順番に値を読み取ります。この例では、最初の `3` が変数 `a` に入り、次の `5` が変数 `b` に入ります。

### 改行された入力
入力が改行されていても、同じように読み取れます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a;
    int b;
    cin >> a >> b;
    cout << a * b << endl;
}
```

入力が次のとき、

**入力**

```text
3
5
```

出力は次のようになります。

**実行結果**

```text
15
```

`cin` は、空白や改行で区切られた値を順番に読み取ります。そのため、`3 5` と書かれていても、`3` と `5` が別々の行に書かれていても、このプログラムでは同じように読み取れます。

### 文字列の入力
文字列を受け取るときは、`string` 型の変数を用意します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s;
    cin >> s;
    cout << "Hello, " << s << "!" << endl;
}
```

入力が次のとき、

**入力**

```text
OSK
```

出力は次のようになります。

**実行結果**

```text
Hello, OSK!
```

`cin >> s;` は、空白で区切られるところまでを文字列として読み取ります。

問題文に書かれている入力形式を見て、必要な変数を用意し、`cin` で順番に受け取りましょう。

## 1.7 演習問題
ここまでの内容を使って、AtCoder のA問題を解いてみましょう。

まずは問題文を読み、自分でコードを書いて提出してみてください。解けなかった場合は、考え方と解答例を見ながら確認しましょう。

### ABC084A - New Year
問題: <https://atcoder.jp/contests/abc084/tasks/abc084_a>

12月30日の $M$ 時から次の年になるまでの時間を求める問題です。

<details>
<summary>解説と解答</summary>

12月30日の $M$ 時から12月31日の0時までは $24 - M$ 時間です。さらに、12月31日の0時から次の年までは $24$ 時間あります。

そのため、答えは $(24 - M) + 24$、つまり $48 - M$ です。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int M;
    cin >> M;
    int ans = 48 - M;
    cout << ans << endl;
}
```

</details>

### ABC076A - Rating Goal
問題: <https://atcoder.jp/contests/abc076/tasks/abc076_a>

現在のレーティング $R$ と、目標のレーティング $G$ が与えられます。次のコンテストで取るべきパフォーマンスを求める問題です。

<details>
<summary>解説と解答</summary>

取るべきパフォーマンスを $x$ とすると、次のコンテスト後のレーティングは $R$ と $x$ の平均になります。

$$
\frac{R + x}{2} = G
$$

この式を変形すると、次のようになります。

$$
x = 2G - R
$$

そのため、答えは $2G - R$ です。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int R;
    int G;
    cin >> R >> G;
    int ans = 2 * G - R;
    cout << ans << endl;
}
```

</details>

### ABC074A - Bichrome Cells
問題: <https://atcoder.jp/contests/abc074/tasks/abc074_a>

$N \times N$ のマス目があり、そのうち $A$ マスを白く塗ります。黒いまま残るマスの数を求める問題です。

<details>
<summary>解説と解答</summary>

全体のマスの数は $N \times N$ です。白く塗ったマスが $A$ 個あるので、黒いまま残るマスの数は $N \times N - A$ です。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    int A;
    cin >> N >> A;
    int ans = N * N - A;
    cout << ans << endl;
}
```
