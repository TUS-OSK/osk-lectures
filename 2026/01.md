## C++ の基本形と出力
C++ のプログラムは、まず次の形を覚えてください。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, OSK!" << endl;
}
```

このプログラムを実行すると、次のように表示されます。

```text
Hello, OSK!
```

最初は、それぞれの行を完全に理解していなくても大丈夫です。まずは「C++ のプログラムはだいたいこの形から始まる」と覚えましょう。

### 各行の意味
`#include <bits/stdc++.h>` は、C++ でよく使う道具をまとめて読み込むための行です。

AtCoder ではこの書き方がよく使われます。文字を出力する `cout` や、後で使う `vector`、`string` なども、この行によって使えるようになります。

`using namespace std;` は、`cout` や `endl` などを短く書けるようにするための行です。

```cpp
int main() {
    cout << "Hello, OSK!" << endl;
}
```

実行結果は次のようになります。

```text
Hello, OSK!
```

ここがプログラムの本体です。

C++ のプログラムは、基本的に `main` の中に書いた処理が上から順番に実行されます。

`cout` は画面に出力するための命令です。`"Hello, OSK!"` のように `"` で囲んだ部分は文字列として扱われます。

`endl` は改行を表します。

## 四則演算
C++ では、数式を書くことで計算できます。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << 3 + 5 << endl;
    cout << 10 - 4 << endl;
    cout << 6 * 7 << endl;
    cout << 20 / 3 << endl;
}
```

このプログラムを実行すると、次のように表示されます。

```text
8
6
42
6
```

C++ で使う主な計算記号は次の通りです。

| 記号 | 意味 |
| --- | --- |
| `+` | 足し算 |
| `-` | 引き算 |
| `*` | 掛け算 |
| `/` | 割り算 |

掛け算には `×` ではなく `*` を使います。割り算には `÷` ではなく `/` を使います。

> [!WARNING]
> 整数どうしを `/` で割ると、答えも整数になります。小数部分は切り捨てられます。
>
> そのため、`20 / 3` の結果は `6.666...` ではなく `6` になります。
>
> 小数として割り算したいときは、どちらか一方を小数にします。
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
>
> int main() {
>     cout << 20.0 / 3 << endl;
>     cout << 20 / 3.0 << endl;
> }
> ```
>
> 実行結果は次のようになります。
>
> ```text
> 6.66667
> 6.66667
> ```
>
> このように書くと、小数として計算されます。

## 剰余演算
割り算の余りを求めるには `%` を使います。これを剰余演算といいます。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << 20 % 3 << endl;
    cout << 10 % 2 << endl;
    cout << 10 % 4 << endl;
}
```

このプログラムを実行すると、次のように表示されます。

```text
2
0
2
```

`20` を `3` で割ると、商は `6`、余りは `2` です。そのため、`20 % 3` の結果は `2` になります。

剰余演算は、数が偶数か奇数かを調べるときや、周期的な処理をするときによく使います。

## 演算子の優先順位
C++ の計算にも、数学と同じように優先順位があります。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << 2 + 3 * 4 << endl;
}
```

実行結果は次のようになります。

```text
14
```

このプログラムでは、先に `3 * 4` が計算されます。そのため、結果は `20` ではなく `14` になります。

`*`、`/`、`%` は、`+`、`-` より先に計算されます。

計算する順番を変えたいときや、順番を分かりやすくしたいときは、括弧 `()` を使います。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << (2 + 3) * 4 << endl;
}
```

実行結果は次のようになります。

```text
20
```

この場合は、先に `2 + 3` が計算されるので、結果は `20` になります。

複雑な式を書くときは、優先順位に頼りすぎず、括弧を使って分かりやすく書くことが大切です。

## 零除算
`0` で割ることを零除算といいます。

C++ では、`/` や `%` の右側に `0` を書いてはいけません。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << 10 / 0 << endl;
    cout << 10 % 0 << endl;
}
```

このプログラムには、正常な実行結果はありません。実行するとエラーになるか、プログラムが途中で止まります。

数学でも `10 / 0` は定義されていません。C++ でも同じように、`0` で割る計算はできません。
