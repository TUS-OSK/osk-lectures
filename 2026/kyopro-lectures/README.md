# 競プロ班講義

新入生講義を終えた人向けの、競技プログラミングの基礎を学ぶ講義資料です。

C++ の基本的な文法を使って、AtCoder の問題をより幅広く解けるようになることを目標にしています。

## 前提

この資料は、次の内容を理解していることを前提にしています。

- C++ の基本形、変数、入力、出力
- `if`、`while`、`for`
- 文字列、配列、関数
- AtCoder で問題を提出する流れ

## 進め方

- まずは講義資料を読み、出てくるコードを自分で実行してください。

- 解説を読む前に、問題の方針を自分で考える時間を取りましょう。

- 計算量を意識して、「なぜこの解法で間に合うのか」を確認してください。

- 分からないことがあれば、対面や Discord の `kyopro-質問` チャンネルで質問してください。

- 余力のある人は、講義で扱ったテーマに対応する AtCoder Beginner Contest の C 問題、D 問題にも挑戦してみてください。
