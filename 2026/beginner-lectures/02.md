## 第1回の復習
第1回では、C++ で簡単なプログラムを書くための基本を扱いました。

### C++ の基本形
C++ のプログラムは、次の形を基本にして書きます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << "Hello, OSK!" << endl;
}
```

**実行結果**

```text
Hello, OSK!
```

`main` の中に書いた処理が、上から順番に実行されます。文の最後にはセミコロン `;` が必要です。

### 計算
C++ では、次の記号を使って計算できます。

| 記号 | 意味 |
| --- | --- |
| `+` | 足し算 |
| `-` | 引き算 |
| `*` | 掛け算 |
| `/` | 割り算 |
| `%` | 割った余り |

整数どうしを `/` で割ると、小数部分は切り捨てられます。余りを求めたいときは `%` を使います。

### 変数
変数は、値に名前をつけて保存しておくためのものです。`+=` などを使うと、変数の値を更新できます。

よく使う型は次の通りです。

| 型 | 保存できる値の例 | 説明 |
| --- | --- | --- |
| `int` | `10`, `-3` | 整数 |
| `long long` | `10000000000` | 大きな整数 |
| `double` | `3.14` | 小数 |
| `char` | `'A'` | 1文字 |
| `string` | `"OSK"` | 文字列 |
| `bool` | `true`, `false` | 真偽値 |

### 入力と出力
入力を受け取るには `cin`、出力するには `cout` を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a;
    int b;
    cin >> a >> b;
    cout << a + b << endl;
}
```

**入力**

```text
3 5
```

**実行結果**

```text
8
```

`cin` は、空白や改行で区切られた値を左から順番に読み取ります。

## 2.1 比較演算子
比較演算子は、2つの値を比べるための記号です。

例えば、`a < b` は「`a` は `b` より小さいか」を表します。

比較した結果は、正しければ `true`、正しくなければ `false` になります。

つまり、比較演算の結果は `bool` 型の値として扱えます。

主な比較演算子は次の通りです。

| 書き方 | 意味 |
| --- | --- |
| `a == b` | `a` と `b` が等しい |
| `a != b` | `a` と `b` が等しくない |
| `a < b` | `a` が `b` より小さい |
| `a <= b` | `a` が `b` 以下 |
| `a > b` | `a` が `b` より大きい |
| `a >= b` | `a` が `b` 以上 |

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3;
    int b = 5;
    cout << (a < b) << endl;
    cout << (a == b) << endl;
}
```

**実行結果**

```text
1
0
```

`true` は `1`、`false` は `0` として出力されます。

> [!NOTE]
> 比較演算の結果は、`bool` 型の変数に代入できます。
>
> **ソースコード**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     int a = 3;
>     int b = 5;
>     bool ok = a < b;
>     cout << ok << endl;
> }
> ```
>
> **実行結果**
>
> ```text
> 1
> ```
>
> この例では、`a < b` が正しいので、`ok` には `true` が入ります。

> [!WARNING]
> 等しいかどうかを調べるときは `==` を使います。
>
> `=` は代入に使う記号なので、意味が違います。

## 2.2 論理演算子
論理演算子は、`bool` 型の値を組み合わせるための記号です。

比較演算の結果も `bool` 型なので、比較演算子と一緒によく使います。

この資料では、読みやすさのために `and`、`or` を使います。

否定には `!` を使います。

主な論理演算子は次の通りです。

| 書き方 | 意味 |
| --- | --- |
| `A and B` | `A` も `B` も正しい |
| `A or B` | `A` か `B` の少なくとも一方が正しい |
| `!A` | `A` が正しくない |

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 12;
    bool ok = 10 <= x and x < 20;
    cout << ok << endl;
}
```

**実行結果**

```text
1
```

この例では、`10 <= x` と `x < 20` がどちらも正しいので、`ok` には `true` が入ります。

`x` が `10` 以上 `20` 未満かどうかを調べたいときは、数学のように `10 <= x < 20` とは書けません。

C++ では、次のように比較を2つに分けて `and` でつなぎます。

**ソースコード**

```cpp
10 <= x and x < 20
```

> [!NOTE]
> C++ では、`and`、`or` の代わりに `&&`、`||` も使えます。
>
> ただし、この資料では意味が読み取りやすい `and`、`or` を主に使います。

## 2.3 if 文
`if` 文を使うと、条件が成り立つときだけ処理を実行できます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x;
    cin >> x;
    if (x >= 10) {
        cout << "OK" << endl;
    }
}
```

**入力**

```text
12
```

**実行結果**

```text
OK
```

`if` の `()` の中には、`bool` 型の値を書きます。

この例では、`x >= 10` という比較演算の結果が `bool` 型の値になります。

`x >= 10` が `true` なら `{}` の中が実行され、`false` なら実行されません。

### else
条件が成り立たなかったときの処理を書きたい場合は、`else` を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x;
    cin >> x;
    if (x >= 10) {
        cout << "OK" << endl;
    } else {
        cout << "NG" << endl;
    }
}
```

**入力**

```text
7
```

**実行結果**

```text
NG
```

`x >= 10` が `true` なら `OK`、`false` なら `NG` が出力されます。

### else if
条件を複数に分けたい場合は、`else if` を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int score;
    cin >> score;
    if (score >= 80) {
        cout << "A" << endl;
    } else if (score >= 60) {
        cout << "B" << endl;
    } else {
        cout << "C" << endl;
    }
}
```

**入力**

```text
75
```

**実行結果**

```text
B
```

`if`、`else if`、`else` は上から順番に判定されます。

この例では、`score >= 80` は `false` ですが、`score >= 60` は `true` です。そのため、`B` が出力されます。

一度どれかの条件に入ると、その後の `else if` や `else` は実行されません。

### bool 型の変数を使う
`if` の `()` の中には `bool` 型の値を書くので、`bool` 型の変数をそのまま使うこともできます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x;
    cin >> x;
    bool ok = 10 <= x and x < 20;
    if (ok) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
}
```

**入力**

```text
15
```

**実行結果**

```text
Yes
```

この例では、`x` が `10` 以上 `20` 未満なら `ok` が `true` になります。

そのため、`if (ok)` の中が実行され、`Yes` が出力されます。

> [!NOTE]
> `if (ok)` は「`ok` が `true` なら」という意味です。
>
> `ok == true` と書くこともできますが、`bool` 型の変数はそのまま `if` に入れられます。

### if 文の中に if 文を書く
`if` 文の `{}` の中には、さらに `if` 文を書くこともできます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x;
    cin >> x;
    if (x >= 0) {
        if (x % 2 == 0) {
            cout << "non-negative even" << endl;
        } else {
            cout << "non-negative odd" << endl;
        }
    } else {
        cout << "negative" << endl;
    }
}
```

**入力**

```text
5
```

**実行結果**

```text
non-negative odd
```

この例では、まず `x >= 0` かどうかを調べています。

`x >= 0` が `true` のときだけ、さらに `x % 2 == 0` かどうかを調べます。

## 2.4 while 文
`while` 文を使うと、条件が成り立っている間、同じ処理をくり返せます。

`if` と同じように、`while` の `()` の中にも `bool` 型の値を書きます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    int i = 1;
    while (i <= N) {
        cout << i << endl;
        i += 1;
    }
}
```

**入力**

```text
3
```

**実行結果**

```text
1
2
3
```

この例では、`i <= N` が `true` の間、`while` の `{}` の中がくり返し実行されます。

最後の `i += 1;` によって、`i` の値が `1` ずつ増えます。

> [!WARNING]
> `while` 文では、条件がいつか `false` になるように書く必要があります。
>
> 条件がずっと `true` のままだと、プログラムが終わらなくなります。

## 2.5 for 文
`for` 文も、同じ処理をくり返すために使います。

くり返す回数が決まっているときは、`while` より `for` の方が書きやすいことが多いです。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    for (int i = 0; i < N; i++) {
        cout << i << endl;
    }
}
```

**入力**

```text
4
```

**実行結果**

```text
0
1
2
3
```

`for` 文は、次の形で書きます。

**書き方**

```text
for (初期化; 条件; 更新) {
    // くり返したい処理
}
```

先ほどの例では、次のように動きます。

| 部分 | 意味 |
| --- | --- |
| `int i = 0` | 最初に `i` を `0` にする |
| `i < N` | この条件が `true` の間くり返す |
| `i++` | 1回くり返すたびに `i` を `1` 増やす |

初期化 → 条件確認 → 処理 → 更新 → 条件確認 → 処理 → 更新 → ... の順に実行されます。

条件確認のときに条件を満たさなかった場合、そこで `for` 文が終わります。

`i++` は、`i += 1` と同じように、`i` の値を `1` 増やす書き方です。

最初は `i++` は `i += 1` と同じだと思って大丈夫です。

`i += 2` と書くと、`i` の値を `2` ずつ増やせます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    for (int i = 0; i <= N; i += 2) {
        cout << i << endl;
    }
}
```

**入力**

```text
6
```

**実行結果**

```text
0
2
4
6
```

この例では、`i += 2` によって `i` が `2` ずつ大きくなります。

`i--` と書くと、`i` の値を `1` 減らせます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    for (int i = N; i >= 1; i--) {
        cout << i << endl;
    }
}
```

**入力**

```text
3
```

**実行結果**

```text
3
2
1
```

この例では、`i--` によって `i` が `1` ずつ小さくなります。

### 合計を求める
くり返しの中で、変数に値を足していくこともよくあります。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    int sum = 0;
    for (int i = 1; i <= N; i++) {
        sum += i;
    }
    cout << sum << endl;
}
```

**入力**

```text
5
```

**実行結果**

```text
15
```

この例では、`1 + 2 + 3 + 4 + 5` が計算されるので、`15` が出力されます。

### 二重 for 文
`for` 文の中に、さらに `for` 文を書くこともできます。

このような書き方を、二重 `for` 文や二重ループと呼びます。

例えば、九九表を出力したいときは、行を表すループと列を表すループを組み合わせます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= 9; j++) {
            cout << i * j;
            if (j < 9) {
                cout << " ";
            }
        }
        cout << endl;
    }
}
```

**実行結果**

```text
1 2 3 4 5 6 7 8 9
2 4 6 8 10 12 14 16 18
3 6 9 12 15 18 21 24 27
4 8 12 16 20 24 28 32 36
5 10 15 20 25 30 35 40 45
6 12 18 24 30 36 42 48 54
7 14 21 28 35 42 49 56 63
8 16 24 32 40 48 56 64 72
9 18 27 36 45 54 63 72 81
```

外側の `for` 文では、`i` が `1` から `9` まで変化します。

内側の `for` 文では、それぞれの `i` について、`j` が `1` から `9` まで変化します。

そのため、`i * j` が全部で $`9 \times 9 = 81`$ 回出力されます。

内側の `for` 文が終わるたびに `cout << endl;` で改行するので、九九表のように9行で表示されます。

## 2.6 break と continue
`break` と `continue` を使うと、くり返しの途中で動きを変えられます。

`break` は、くり返しをそこで終了します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    for (int i = 1; i <= N; i++) {
        if (i == 4) {
            break;
        }
        cout << i << endl;
    }
}
```

**入力**

```text
6
```

**実行結果**

```text
1
2
3
```

この例では、`i == 4` になった時点で `break` するので、くり返しが終了します。

`continue` は、今の回の残りの処理を飛ばして、次のくり返しに進みます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    for (int i = 1; i <= N; i++) {
        if (i % 2 == 0) {
            continue;
        }
        cout << i << endl;
    }
}
```

**入力**

```text
6
```

**実行結果**

```text
1
3
5
```

この例では、`i` が偶数のときに `continue` します。

そのため、偶数は出力されず、奇数だけが出力されます。

## 2.7 変数のスコープ
変数を使える範囲のことを、スコープといいます。

基本的に、`{}` の中で宣言した変数は、その `{}` の中でしか使えません。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 10;
    if (x >= 5) {
        int y = 20;
        cout << y << endl;
    }
    cout << x << endl;
}
```

**実行結果**

```text
20
10
```

この例では、`x` は `main` の `{}` の中で宣言されているので、`main` の中で使えます。

`y` は `if` の `{}` の中で宣言されているので、その中でだけ使えます。

> [!WARNING]
> 次のように、`if` の `{}` の外で `y` を使うことはできません。
>
> **書いてはいけない例**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     int x = 10;
>     if (x >= 5) {
>         int y = 20;
>     }
>     cout << y << endl;
> }
> ```
>
> `y` を使えるのは、宣言した `if` の `{}` の中だけです。

`for` 文の中で宣言した変数にも、スコープがあります。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    for (int i = 0; i < 3; i++) {
        cout << i << endl;
    }
}
```

**実行結果**

```text
0
1
2
```

この例の `i` は、`for` 文の中で使うための変数です。

`for` 文の外で `i` を使うことはできません。

## 2.8 文字列
`string` は文字列を扱う型です。

第1回では、`string` と `char` の基本を扱いました。

ここでは、文字列の一部を取り出したり、書き換えたりする方法を見ます。

### 各文字へのアクセス
文字列のインデックス `i` の文字には、`s[i]` でアクセスできます。

インデックスは `0` から始まります。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "OSK";
    cout << s[0] << endl;
    cout << s[1] << endl;
    cout << s[2] << endl;
}
```

**実行結果**

```text
O
S
K
```

`s[0]` は1文字目、`s[1]` は2文字目、`s[2]` は3文字目を表します。

`s[i]` の結果は `char` 型の値です。

### 文字列の長さ
文字列の長さは `s.size()` で取得できます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s;
    cin >> s;
    cout << s.size() << endl;
}
```

**入力**

```text
OSK
```

**実行結果**

```text
3
```

長さが `N` の文字列で使えるインデックスは、`0` から `N - 1` までです。

### 文字列の書き換え
`s[i]` に `char` 型の値を代入すると、文字列の一部を書き換えられます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "Hello";
    s[0] = 'M';
    cout << s << endl;
}
```

**実行結果**

```text
Mello
```

`char` 型の値は、`'M'` のようにシングルクォート `'` で囲みます。

### 文字の比較
`s[i]` は `char` 型なので、`'A'` のような文字と比較できます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s;
    cin >> s;
    if (s[0] == 'O') {
        cout << "starts with O" << endl;
    } else {
        cout << "does not start with O" << endl;
    }
}
```

**入力**

```text
OSK
```

**実行結果**

```text
starts with O
```

`"O"` は `string` 型の文字列、`'O'` は `char` 型の文字です。

`s[0]` と比較するときは、`'O'` を使います。

### ループとの組み合わせ
文字列と `for` 文を組み合わせると、文字列の中身を1文字ずつ調べられます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s;
    cin >> s;
    int count = 0;
    for (int i = 0; i < s.size(); i++) {
        if (s[i] == 'O') {
            count++;
        }
    }
    cout << count << endl;
}
```

**入力**

```text
LOOOOL
```

**実行結果**

```text
4
```

この例では、文字列の中に `'O'` が何個あるかを数えています。

> [!NOTE]
> 環境によっては、`i < s.size()` の部分で警告が出ることがありますが、問題ありません。

### 範囲外アクセス
文字列の長さが `N` のとき、使えるインデックスは `0` から `N - 1` までです。

その範囲の外にアクセスしてはいけません。

> [!WARNING]
> 次のコードでは、長さ `5` の文字列に対して `s[10]` を使っています。
>
> **書いてはいけない例**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     string s = "hello";
>     cout << s[10] << endl;
> }
> ```
>
> `[]` では範囲外かどうかを自動で確認してくれません。
>
> 範囲外にアクセスすると、変な値が出たり、プログラムが止まったりすることがあります。

> [!NOTE]
> この講義では、`string` や `char` では基本的に半角英数字を扱うことを想定します。
>
> 日本語のような全角文字は、`s[i]` で1文字ずつ正しく扱えないことがあります。
>
> AtCoder の初心者向けの問題では、まずは半角英数字からなる文字列を扱うことが多いです。

### 文字列の比較
`string` 型の値どうしは、比較演算子で比較できます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s1 = "ABC";
    string s2 = "ABC";
    string s3 = "XYZ";
    if (s1 == s2) {
        cout << "same" << endl;
    }
    if (s1 < s3) {
        cout << "small" << endl;
    }
}
```

**実行結果**

```text
same
small
```

`==` は、2つの文字列が完全に同じかどうかを調べます。

`<`、`<=`、`>`、`>=` は辞書順で比較します。

### 文字列の連結
`+` を使うと、文字列どうしを連結できます。

`+=` を使って、今ある文字列の後ろに追加することもできます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "Hello";
    cout << s + ", world!" << endl;
    s += ", OSK!";
    cout << s << endl;
}
```

**実行結果**

```text
Hello, world!
Hello, OSK!
```

`string` 型では、数値のように `-`、`*`、`/`、`%` を使うことはできません。

### string と char の比較
`string` 型と `char` 型は別の型です。

そのため、`string` 型の値と `char` 型の値をそのまま `==` で比較することはできません。

> [!WARNING]
> 次のコードはコンパイルできません。
>
> **書いてはいけない例**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     string s = "A";
>     char c = 'A';
>     if (s == c) {
>         cout << "same" << endl;
>     }
> }
> ```
>
> `string` 型と `char` 型を比較したいときは、型をそろえる必要があります。

例えば、1文字目どうしを比べたいなら、`s[0]` を使って `char` 型どうしを比較します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "A";
    char c = 'A';
    if (s[0] == c) {
        cout << "same" << endl;
    }
}
```

**実行結果**

```text
same
```

### 文字列と文字の連結
`string` 型の値には、`char` 型の値を連結できます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "Hello";
    char c = '!';
    cout << s + c << endl;
}
```

**実行結果**

```text
Hello!
```

> [!NOTE]
> 改行などの特殊な文字は、エスケープシーケンスで表せます。
>
> よく使うものは `\n` です。
>
> **ソースコード**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     cout << "Hello\nOSK" << endl;
> }
> ```
>
> **実行結果**
>
> ```text
> Hello
> OSK
> ```
>
> 代表的なエスケープシーケンスは次の通りです。
>
> | 書き方 | 意味 |
> | --- | --- |
> | `\n` | 改行 |
> | `\"` | ダブルクォート `"` |
> | `\'` | シングルクォート `'` |
> | `\\` | バックスラッシュ `\` |
> | `\t` | タブ |

## 2.9 型の変換
ここでは、これまで学んだ `int`、`long long`、`double`、`char`、`string` の間で値を変換して使う方法を扱います。

型が違う値は、そのままでは同じように扱えないことがあります。

### 型が違う値
見た目が似ていても、型が違うと意味が変わります。

| 値 | 型 |
| --- | --- |
| `123` | `int` |
| `"123"` | `string` |
| `'7'` | `char` |
| `7.0` | `double` |

例えば、`123` は整数ですが、`"123"` は文字列です。

型によって、`+` の意味も変わります。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 123;
    string s = "123";

    cout << x + 10 << endl;
    cout << s + "10" << endl;
}
```

**実行結果**

```text
133
12310
```

`int` 型の `x + 10` は足し算です。

一方で、`string` 型の `s + "10"` は文字列の連結です。

### 数値型同士の変換
型を明示的に変換することを、キャストといいます。

この資料では、次の書き方を使います。

**書き方**

```text
(変換したい型)値
```

例えば、`int` 型の変数 `a` を `double` 型として使いたいときは、`(double)a` と書きます。

### 整数を小数として計算する
整数どうしを `/` で割ると、小数部分は切り捨てられます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 7;
    int b = 2;

    cout << a / b << endl;
    cout << (double)a / b << endl;
}
```

**実行結果**

```text
3
3.5
```

`a / b` は `int` 型どうしの割り算なので、結果も整数として扱われます。

`(double)a / b` では、割り算を行う前に `a` を `double` 型に変換しています。

そのため、小数を含む結果になります。

> [!IMPORTANT]
> 小数部分を残したい場合は、割り算を行う前に `double` 型へ変換します。

### 小数を整数に変換する
`double` 型の値を `int` 型にキャストすることもできます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    double x = 3.14;
    double y = -3.14;

    cout << (int)x << endl;
    cout << (int)y << endl;
}
```

**実行結果**

```text
3
-3
```

> [!WARNING]
> `double` 型から `int` 型に変換すると、四捨五入ではなく、小数部分が取り除かれて `0` に近い整数になります。

小数を「必ず小さい方の整数」にしたいときは `floor`、「必ず大きい方の整数」にしたいときは `ceil` を使います。

| 書き方 | 意味 |
| --- | --- |
| `(int)x` | 小数部分を取り除く |
| `floor(x)` | `x` 以下の最大の整数 |
| `ceil(x)` | `x` 以上の最小の整数 |

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    double x = 3.14;
    double y = -3.14;

    cout << (int)x << " " << floor(x) << " " << ceil(x) << endl;
    cout << (int)y << " " << floor(y) << " " << ceil(y) << endl;
}
```

**実行結果**

```text
3 3 4
-3 -4 -3
```

`3.14` の場合は `(int)x` と `floor(x)` がどちらも `3` になります。

一方で、`-3.14` の場合は `(int)y` は `-3` ですが、`floor(y)` は `-4` になります。

> [!NOTE]
> `floor` と `ceil` の結果は `double` 型です。
>
> 整数として変数に入れたい場合は、`int a = floor(x);` のように書きます。

### 大きな整数と long long
競技プログラミングでは、`int` 型で扱える値はおよそ $`2 \times 10^9`$ までと考えておくとよいです。

計算結果が大きくなる場合は、`long long` 型を使います。

ただし、答えを入れる変数だけを `long long` 型にしても安全とは限りません。

計算結果が型で扱える範囲を超えてしまうことを、オーバーフローといいます。

オーバーフローすると、正しい値が得られるとは限りません。

**危険な例**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 100000;
    int b = 100000;

    long long ans = a * b;
    cout << ans << endl;
}
```

**実行結果の例**

```text
1410065408
```

この例では、`a * b` が先に `int` 型として計算されます。

そのため、答えを入れる変数が `long long` 型でも、正しい値にならないことがあります。

環境によっては、上の例とは違う値が出ることもあります。

安全に計算するには、計算前に片方を `long long` 型に変換します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 100000;
    int b = 100000;

    long long ans = (long long)a * b;
    cout << ans << endl;
}
```

**実行結果**

```text
10000000000
```

`(long long)a * b` では、掛け算を行う前に `a` を `long long` 型に変換しています。

一方で、次の書き方では変換するタイミングが遅すぎます。

> [!WARNING]
> **書いてはいけない例**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     int a = 100000;
>     int b = 100000;
>
>     long long ans = (long long)(a * b);
>     cout << ans << endl;
> }
> ```
>
> この場合は、`a * b` が先に `int` 型として計算されます。
>
> 先に `int` 型の計算でオーバーフローしてしまうので、その後で `long long` 型に変換しても、正しい値には戻りません。

### 異なる数値型を一緒に使う
異なる数値型を一緒に使うと、より広い型に合わせて計算されます。

| 計算に使う型 | 計算結果として扱われる型 |
| --- | --- |
| `int` と `int` | `int` |
| `int` と `long long` | `long long` |
| `int` と `double` | `double` |
| `long long` と `double` | `double` |

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3;
    double b = 0.5;

    cout << a + b << endl;
}
```

**実行結果**

```text
3.5
```

この例では、`int` 型と `double` 型を足しているので、結果は `double` 型として扱われます。

### 小数を指定した桁数で出力する
小数を指定した桁数で出力したいときは、`fixed` と `setprecision` を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3;
    int b = 1;

    double x = (double)b / a;

    cout << fixed << setprecision(5);
    cout << x << endl;
}
```

**実行結果**

```text
0.33333
```

`fixed << setprecision(5)` と書くと、小数点以下を `5` 桁で出力します。

### string 型から数値型への変換
`string` 型の値を数値型に変換したいときは、次の関数を使います。

| 変換 | 関数 | 例 |
| --- | --- | --- |
| `string` → `int` | `stoi` | `stoi("123")` |
| `string` → `long long` | `stoll` | `stoll("10000000000")` |
| `string` → `double` | `stod` | `stod("3.14")` |

文字列のまま足す場合と、数値に変換してから足す場合では、結果が変わります。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "123";

    cout << s + "10" << endl;
    cout << stoi(s) + 10 << endl;
}
```

**実行結果**

```text
12310
133
```

`s + "10"` は文字列の連結です。

`stoi(s) + 10` は、`s` を `int` 型に変換してから足し算しています。

`stoi`、`stoll`、`stod` は次のように使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string a = "123";
    string b = "10000000000";
    string c = "3.14";

    int x = stoi(a);
    long long y = stoll(b);
    double z = stod(c);

    cout << x + 1 << endl;
    cout << y + 1 << endl;
    cout << z + 1 << endl;
}
```

**実行結果**

```text
124
10000000001
4.14
```

### 数値型から string 型への変換
数値型の値を `string` 型に変換したいときは、`to_string` を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 123;
    string s = to_string(x);

    cout << s + "yen" << endl;
}
```

**実行結果**

```text
123yen
```

整数を文字列に変換すると、各桁を文字として扱えます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 12345;
    string s = to_string(x);

    for (int i = 0; i < s.size(); i++) {
        cout << s[i] << endl;
    }
}
```

**実行結果**

```text
1
2
3
4
5
```

### char 型と文字コード
`char` 型は、文字を1つ保存するための型です。

プログラム上では `'A'` や `'7'` のように文字として書きますが、コンピュータの内部では文字に対応する整数として表現されています。

この文字に対応する整数を、文字コードといいます。

文字コードにはいくつか種類がありますが、半角英数字では ASCII コードという文字コードの順番を利用できます。

数値そのものを丸暗記する必要はありません。各範囲が連続していることが重要です。

| 文字 | ASCII コード |
| --- | ---: |
| `'0'` | 48 |
| `'9'` | 57 |
| `'A'` | 65 |
| `'Z'` | 90 |
| `'a'` | 97 |
| `'z'` | 122 |

`char` 型の値を `int` 型の変数に代入すると、その文字に対応する文字コードの値として扱われます。

次の例では、`'A'` に対応する ASCII コードである `65` が出力されます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'A';
    int x = c;

    cout << x << endl;
}
```

**実行結果**

```text
65
```

### 数字を表す文字と整数の変換
数字を表す `char` 型の値を整数にするには、`c - '0'` と書きます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = '7';
    int x = c - '0';
    cout << x << endl;
}
```

**実行結果**

```text
7
```

`0` から `9` までの整数を数字の文字にするには、`'0' + x` と書きます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x = 7;
    char c = '0' + x;
    cout << c << endl;
}
```

**実行結果**

```text
7
```

### 英大文字・英小文字・数字の判定
文字コードの順番を利用すると、文字の種類を判定できます。

| 判定したいもの | 条件 |
| --- | --- |
| 英大文字 | `'A' <= c and c <= 'Z'` |
| 英小文字 | `'a' <= c and c <= 'z'` |
| 数字 | `'0' <= c and c <= '9'` |

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'G';

    if ('A' <= c and c <= 'Z') {
        cout << "upper" << endl;
    } else if ('a' <= c and c <= 'z') {
        cout << "lower" << endl;
    } else if ('0' <= c and c <= '9') {
        cout << "digit" << endl;
    }
}
```

**実行結果**

```text
upper
```

### 英大文字・英小文字の変換
英小文字を英大文字に変換するには、次のように書けます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'b';
    c = c + ('A' - 'a');

    cout << c << endl;
}
```

**実行結果**

```text
B
```

英小文字と英大文字は、どちらもアルファベット順に連続して並んでいます。

そのため、`'a'` と `'A'` の差を足すと、同じ位置の英大文字に変換できます。

例えば、`'b'` は英小文字の中で `'a'` の次の文字です。

`'A' - 'a'` を足すと、英大文字の中で `'A'` の次の文字である `'B'` になります。

文字列全体を英大文字に変換することもできます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string s = "osk";

    for (int i = 0; i < s.size(); i++) {
        s[i] = s[i] + ('A' - 'a');
    }

    cout << s << endl;
}
```

**実行結果**

```text
OSK
```

> [!WARNING]
> `c = c + ('A' - 'a');` という書き方は、対象の文字が英小文字であることが保証されている場合に使います。

> [!NOTE]
> 逆に、英大文字を英小文字に変換したいときは、`'a' - 'A'` を足します。
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     char c = 'B';
>     c = c + ('a' - 'A');
>
>     cout << c << endl;
> }
> ```
>
> この場合も、対象の文字が英大文字であることが保証されている場合に使います。

### 型の変換のまとめ
この節で扱った変換方法をまとめます。

| やりたいこと | 書き方 |
| --- | --- |
| `int` 型の値を `double` 型に変換する | `(double)x` |
| `double` 型の値を `int` 型に変換する | `(int)x` |
| `int` 型の値を `long long` 型に変換する | `(long long)x` |
| `string` 型の値を `int` 型に変換する | `stoi(s)` |
| `string` 型の値を `long long` 型に変換する | `stoll(s)` |
| `string` 型の値を `double` 型に変換する | `stod(s)` |
| 数値型の値を `string` 型に変換する | `to_string(x)` |
| 数字を表す `char` 型の値を `int` 型に変換する | `c - '0'` |
| `0` から `9` までの整数を数字の文字に変換する | `'0' + x` |
