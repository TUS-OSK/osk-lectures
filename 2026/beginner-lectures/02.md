## 第1回の復習
第1回では、C++ で簡単なプログラムを書くための基本を扱いました。

### C++ の基本形
C++ のプログラムは、次の形を基本にして書きます。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    cout << "Hello, OSK!" << endl;
}
```

`main` の中に書いた処理が、上から順番に実行されます。文の最後にはセミコロン `;` が必要です。

### 計算
C++ では、次の記号を使って計算できます。

| 記号 | 意味 |
| --- | --- |
| `+` | 足し算 |
| `-` | 引き算 |
| `*` | 掛け算 |
| `/` | 割り算 |
| `%` | 割った余り |

整数どうしを `/` で割ると、小数部分は切り捨てられます。余りを求めたいときは `%` を使います。

### 変数
変数は、値に名前をつけて保存しておくためのものです。

よく使う型は次の通りです。

| 型 | 保存できる値の例 | 説明 |
| --- | --- | --- |
| `int` | `10`, `-3` | 整数 |
| `long long` | `10000000000` | 大きな整数 |
| `double` | `3.14` | 小数 |
| `char` | `'A'` | 1文字 |
| `string` | `"AtCoder"` | 文字列 |
| `bool` | `true`, `false` | 真偽値 |

### 入力と出力
入力を受け取るには `cin`、出力するには `cout` を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a;
    int b;
    cin >> a >> b;
    cout << a + b << endl;
}
```

`cin` は、空白や改行で区切られた値を左から順番に読み取ります。

## 2.1 比較演算子
比較演算子は、2つの値を比べるための記号です。

例えば、`a < b` は「`a` は `b` より小さいか」を表します。

比較した結果は、正しければ `true`、正しくなければ `false` になります。

つまり、比較演算の結果は `bool` 型の値として扱えます。

主な比較演算子は次の通りです。

| 書き方 | 意味 |
| --- | --- |
| `a == b` | `a` と `b` が等しい |
| `a != b` | `a` と `b` が等しくない |
| `a < b` | `a` が `b` より小さい |
| `a <= b` | `a` が `b` 以下 |
| `a > b` | `a` が `b` より大きい |
| `a >= b` | `a` が `b` 以上 |

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a = 3;
    int b = 5;
    cout << (a < b) << endl;
    cout << (a == b) << endl;
}
```

**実行結果**

```text
1
0
```

`true` は `1`、`false` は `0` として出力されます。

> [!NOTE]
> 比較演算の結果は、`bool` 型の変数に代入できます。
>
> **ソースコード**
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     int a = 3;
>     int b = 5;
>     bool ok = a < b;
>     cout << ok << endl;
> }
> ```
>
> **実行結果**
>
> ```text
> 1
> ```
>
> この例では、`a < b` が正しいので、`ok` には `true` が入ります。

> [!WARNING]
> 等しいかどうかを調べるときは `==` を使います。
>
> `=` は代入に使う記号なので、意味が違います。

## 2.2 代入演算子
代入演算子は、変数に値を入れるための記号です。

第1回で使った `=` も代入演算子です。

**ソースコード**

```cpp
int x = 10;
x = 20;
```

このコードでは、最初に `x` に `10` が入り、その後 `x` の値が `20` に変わります。

### 値を増やす代入
変数の値を増やしたいときは、次のように書けます。

**ソースコード**

```cpp
int x = 10;
x = x + 3;
```

これは「今の `x` に `3` を足して、その結果をもう一度 `x` に入れる」という意味です。

同じことは、次のように短く書けます。

**ソースコード**

```cpp
int x = 10;
x += 3;
```

### よく使う代入演算子
よく使う代入演算子は次の通りです。

| 書き方 | 同じ意味 |
| --- | --- |
| `x += a` | `x = x + a` |
| `x -= a` | `x = x - a` |
| `x *= a` | `x = x * a` |
| `x /= a` | `x = x / a` |
| `x %= a` | `x = x % a` |

特に、繰り返しの中で合計を求めるときに `+=` はよく使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int sum = 0;
    sum += 3;
    sum += 5;
    cout << sum << endl;
}
```

**実行結果**

```text
8
```
