# 新入生講義 第2回 解説

## ABC053A - ABC/ARC

問題: <https://atcoder.jp/contests/abc053/tasks/abc053_a>

$`x`$ が $`1200`$ 未満なら `ABC`、そうでなければ `ARC` を出力します。

条件によって出力を変えたいので、`if` 文を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int x;
    cin >> x;
    if (x < 1200) {
        cout << "ABC" << endl;
    } else {
        cout << "ARC" << endl;
    }
}
```

## ABC061A - Between Two Integers

問題: <https://atcoder.jp/contests/abc061/tasks/abc061_a>

$`C`$ が $`A`$ 以上 $`B`$ 以下なら `Yes`、そうでなければ `No` を出力します。

「$`A`$ 以上」と「$`B`$ 以下」の両方を満たす必要があるので、`and` を使います。

```math
A \leq C \leq B
```

C++ では、上のような条件は次のように書きます。

```cpp
A <= C and C <= B
```

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int A;
    int B;
    int C;
    cin >> A >> B >> C;
    if (A <= C and C <= B) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
}
```

## ABC049A - UOIAUAI

問題: <https://atcoder.jp/contests/abc049/tasks/abc049_a>

母音は `a`、`e`、`i`、`o`、`u` の5つです。

$`c`$ がこのどれかなら `vowel`、そうでなければ `consonant` を出力します。

複数の条件のうち、どれか1つでも成り立てばよいので、`or` を使います。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c;
    cin >> c;
    if (c == 'a' or c == 'e' or c == 'i' or c == 'o' or c == 'u') {
        cout << "vowel" << endl;
    } else {
        cout << "consonant" << endl;
    }
}
```

## ABC095A - Something on It

問題: <https://atcoder.jp/contests/abc095/tasks/abc095_a>

最初の値段は $`700`$ 円です。

文字列 $`S`$ の中に `o` が1つあるたびに、値段が $`100`$ 円増えます。

長さ $`3`$ の文字列なので、`for` 文で `S[0]`、`S[1]`、`S[2]` を順番に調べます。

`S[i]` が `'o'` なら、答えに $`100`$ を足します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    string S;
    cin >> S;
    int ans = 700;
    for (int i = 0; i < 3; i++) {
        if (S[i] == 'o') {
            ans += 100;
        }
    }
    cout << ans << endl;
}
```

## ABC060B - Choose Integers

問題: <https://atcoder.jp/contests/abc060/tasks/abc060_b>

$`A`$ の倍数をいくつか試して、その値を $`B`$ で割った余りが $`C`$ になるかを調べます。

$`A \times i`$ を $`B`$ で割った余りは、次の式で求められます。

```math
(A \times i) \bmod B
```

この値が $`C`$ になる $`i`$ が見つかれば `YES` です。

$`i`$ は $`1`$ から $`B`$ まで試せば十分です。余りの出方は周期的なので、$`B`$ 回試して見つからなければ作れません。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int A;
    int B;
    int C;
    cin >> A >> B >> C;
    bool ok = false;
    for (int i = 1; i <= B; i++) {
        if ((A * i) % B == C) {
            ok = true;
            break;
        }
    }
    if (ok) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
}
```
