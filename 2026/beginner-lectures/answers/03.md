## ABC090A - Diagonal String

問題: <https://atcoder.jp/contests/abc090/tasks/abc090_a>

3行3列の文字を、2次元配列 `c` に受け取ります。

左上から右下への対角線上の文字は、次の3つです。

- 1行目の1文字目: `c[0][0]`
- 2行目の2文字目: `c[1][1]`
- 3行目の3文字目: `c[2][2]`

行番号と列番号が同じ場所を出力すればよいので、`for` 文で `c[i][i]` を順番に出力します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    vector<vector<char>> c(3, vector<char>(3));
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            cin >> c[i][j];
        }
    }

    for (int i = 0; i < 3; i++) {
        cout << c[i][i];
    }
    cout << endl;
}
```

## ABC273A - A Recursive Function

問題: <https://atcoder.jp/contests/abc273/tasks/abc273_a>

問題文の関数 $`f`$ は、次のように定義されています。

```math
f(0) = 1
```

```math
f(k) = k \times f(k - 1)
```

これは階乗と同じ形です。

再帰関数で書くなら、`n == 0` のときに `1` を返し、それ以外のときは `n * f(n - 1)` を返します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;

int f(int n) {
    if (n == 0) {
        return 1;
    }
    return n * f(n - 1);
}

int main() {
    int N;
    cin >> N;
    cout << f(N) << endl;
}
```

## ABC102B - Maximum Difference

問題: <https://atcoder.jp/contests/abc102/tasks/abc102_b>

2つの要素の差の絶対値を最大にするには、最大値と最小値を選べばよいです。

そのため、配列の中の最大値と最小値を求めて、差を出力します。

ここではソートを使わず、`for` 文で配列を順番に見ながら最大値と最小値を更新します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    vector<int> A(N);
    for (int i = 0; i < N; i++) {
        cin >> A[i];
    }

    int max_value = A[0];
    int min_value = A[0];
    for (int i = 0; i < N; i++) {
        if (A[i] > max_value) {
            max_value = A[i];
        }
        if (A[i] < min_value) {
            min_value = A[i];
        }
    }

    int ans = max_value - min_value;
    cout << ans << endl;
}
```

## ABC088B - Card Game for Two

問題: <https://atcoder.jp/contests/abc088/tasks/abc088_b>

Alice も Bob も自分の得点をできるだけ大きくしたいので、毎回残っているカードの中で一番大きい数を取ります。

そのため、カードを大きい順に並べます。

大きい順に見て、偶数番目なら Alice、奇数番目なら Bob が取ると考えればよいです。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    cin >> N;
    vector<int> a(N);
    for (int i = 0; i < N; i++) {
        cin >> a[i];
    }

    sort(a.rbegin(), a.rend());

    int alice = 0;
    int bob = 0;
    for (int i = 0; i < N; i++) {
        if (i % 2 == 0) {
            alice += a[i];
        } else {
            bob += a[i];
        }
    }

    cout << alice - bob << endl;
}
```

## ABC272B - Everyone is Friends

問題: <https://atcoder.jp/contests/abc272/tasks/abc272_b>

どの2人が同じ舞踏会に参加したことがあるかを、2次元配列 `met` で管理します。

`met[i][j]` が `true` なら、人 `i` と人 `j` は少なくとも1回同じ舞踏会に参加した、という意味にします。

舞踏会ごとに参加者の配列 `x` を作り、その中の2人の組をすべて `true` にします。

最後に、すべての2人の組について `met[i][j]` が `true` かを確認します。

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    int M;
    cin >> N >> M;

    vector<vector<bool>> met(N, vector<bool>(N, false));

    for (int i = 0; i < M; i++) {
        int k;
        cin >> k;
        vector<int> x(k);
        for (int j = 0; j < k; j++) {
            cin >> x[j];
            x[j]--;
        }

        for (int j = 0; j < k; j++) {
            for (int l = j + 1; l < k; l++) {
                met[x[j]][x[l]] = true;
                met[x[l]][x[j]] = true;
            }
        }
    }

    bool ok = true;
    for (int i = 0; i < N; i++) {
        for (int j = i + 1; j < N; j++) {
            if (!met[i][j]) {
                ok = false;
            }
        }
    }

    if (ok) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
}
```
