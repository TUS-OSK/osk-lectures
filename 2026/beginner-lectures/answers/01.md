# 新入生講義 第1回 解説

## ABC084A - New Year

問題: <https://atcoder.jp/contests/abc084/tasks/abc084_a>

12月30日の $`M`$ 時から12月31日の0時までの時間は、次の式で求められます。

```math
24 - M
```

さらに、12月31日の0時から次の年までは $`24`$ 時間あります。

そのため、答えは次のようになります。

```math
(24 - M) + 24 = 48 - M
```

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int M;
    cin >> M;
    int ans = 48 - M;
    cout << ans << endl;
}
```

## ABC076A - Rating Goal

問題: <https://atcoder.jp/contests/abc076/tasks/abc076_a>

取るべきパフォーマンスを $`x`$ とすると、次のコンテスト後のレーティングは $`R`$ と $`x`$ の平均になります。

つまり、次の式が成り立ちます。

```math
\frac{R + x}{2} = G
```

この式を変形すると、次のようになります。

```math
x = 2G - R
```

そのため、答えは次の式です。

```math
2G - R
```

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int R;
    int G;
    cin >> R >> G;
    int ans = 2 * G - R;
    cout << ans << endl;
}
```

## ABC074A - Bichrome Cells

問題: <https://atcoder.jp/contests/abc074/tasks/abc074_a>

全体のマスの数は次の式で求められます。

```math
N \times N
```

白く塗ったマスが $`A`$ 個あるので、黒いまま残るマスの数は次の式で求められます。

```math
N \times N - A
```

**ソースコード**

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int N;
    int A;
    cin >> N >> A;
    int ans = N * N - A;
    cout << ans << endl;
}
```
