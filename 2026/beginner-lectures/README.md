# 新入生講義

プログラミングをほとんど触ったことがない人向けの講義資料です。

C++ を使って AtCoder の問題に挑戦できるようになることを目標にしています。

## 前提

この資料は、次の準備が終わっていることを前提にしています。

- C++ のプログラムを書けるエディタが使える
- ターミナルで `g++` を実行できる
- AtCoder のアカウントを持っている

## 進め方

- 資料に出てくるコードは、読むだけでなく自分で入力して実行してください。

- 実行する前に「何が出力されるか」を予想してから実行すると、理解しやすくなります。

- エラーが出たときは、エラーメッセージを読み、どの行の近くで問題が起きているかを確認してください。

- 分からないことがあれば、対面や Discord の `kyopro-質問` チャンネルで質問してください。

- 余力のある人は、[APG4b](https://atcoder.jp/contests/apg4b) の該当するページを読むことをおすすめします。
